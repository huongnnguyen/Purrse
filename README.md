# Purrse

A private, web-based personal finance tracker — built from scratch to learn full-stack development (Spring Boot + PostgreSQL + React), with the eventual goal of an intelligent, permission-based allocation system for savings goals.

## Stack
- **Frontend:** React (not started yet)
- **Backend:** Java 25 / Spring Boot 4.1.1, Gradle
- **Database:** PostgreSQL 18

### Phase 1 — Database Schema (hand-written SQL) ✅
Database: `purrse_dev`, created and managed via `psql`.

Four tables built by hand (not generated by Hibernate) to actually understand the schema before automating it:

```sql
users        (id, name)
accounts     (id, user_id → users, name, type, balance)
transactions (id, account_id → accounts, merchant, amount, date, category, type)
goals        (id, user_id → users, name, target_amount, current_amount, deadline)
```

Constraints in place:
- Foreign keys linking accounts → users, transactions → accounts, goals → users
- `NUMERIC(10,2)` used for all money fields (never floating point)
- `CHECK` constraints: `goals.current_amount >= 0`, `accounts.balance >= 0`

Seeded with test data (1 user, 1 checking account, 10 transactions mixing income/expenses across Groceries, Dining, Merchandise, Cable categories) and verified with working queries:
- Total spend by category
- Income vs. expenses
